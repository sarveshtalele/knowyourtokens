# Getting help

- **Usage questions / ideas** — open a [GitHub Discussion](https://github.com/sarveshtalele/tokentelemetry/discussions)
  (or an issue labelled `question` if Discussions is disabled).
- **Bugs** — open an issue using the *Bug report* template. Include `tokentelemetry doctor` output.
- **Security issues** — never in public; see [`SECURITY.md`](SECURITY.md).

Token Telemetry is maintained on a best-effort, volunteer basis. There is no paid support.
