# Getting help

- **Usage questions / ideas** — open a [GitHub Discussion](https://github.com/sarveshtalele/knowyourtokens/discussions)
  (or an issue labelled `question` if Discussions is disabled).
- **Bugs** — open an issue using the *Bug report* template. Include `knowyourtokens doctor` output, and
  which agent the data came from (Claude Code, Codex CLI, Gemini CLI, OpenCode, or the ingest API) and
  its version.
- **An agent's numbers look wrong or a new agent version isn't picked up** — agents change their log
  formats; open an issue with the agent, its version, and (if you can share it) a redacted sample
  line of its session file.
- **Problems with an agent itself** — report those to the agent's vendor. Know Your Tokens is an
  independent project, not affiliated with Anthropic, OpenAI, Google or any agent vendor.
- **Security issues** — never in public; see [`SECURITY.md`](SECURITY.md).

Know Your Tokens is maintained on a best-effort, volunteer basis. There is no paid support.
